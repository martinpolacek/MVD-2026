# Cvičení 1 - MetaCentrum a Git

1. Na MetaCentru spusťte dávkovou úlohu, která spočítá něco jednoduchého, ale potřebuje alespoň 20 GB RAM.
2. Založte si na GitHubu repozitář `MVD-2026-Prijmeni` a nasdílejte ho s uživatelem [@martinpolacek](https://github.com/martinpolacek).
3. Do repozitáře nahrajte skripty a výstupy úlohy.
